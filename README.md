A single-line safety warning label for every human being, written for the
[Warning Label for Humans: One Line, Big Laugh](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85)
bounty on [make.fun](https://make.fun). The program writes the label to
`output/entry.txt`: one line, 160 characters or fewer, funny first and
plausible second — the way a real printed label would read, if humans came
with one.

## Run

```sh
python3 main.py
cat output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else instead.
